# 数据查询探索与自助分析平台

面向数据查询编辑器、可视化探索、自助分析看板、数据导出分发、分析笔记协作与查询历史管理的本地化数据分析应用平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `data-explore-selfservice:entries` 这一项，或调用 `resetModule(模块)`。

## 看板组合数据快照与分享

看板分享后内容不再随基础图表悄悄变化：在自助看板页「创建看板组合」（或在看板行上执行
「生成分享组合」）时，`frontend/src/api/dashboard-combo.ts` 会解析看板布局的包含图表组、
布局列数、自动刷新秒、全屏模式与背景主题，生成一份不可变的**看板组合数据快照**
（localStorage 键 `data-explore-selfservice:dashboard-combos`）：

- 快照逐项保存看板名称、包含图表组、布局列数和来源配置（来源布局编号、生成时状态），
  分享页 `/share/view/<组合编号>` 提供逐项复核表；每张图表保留配置编号与当前字段映射
  版本（`FM-` 前缀），失效引用单独标注来源，不会把整屏替换成空白。
- 同一布局内容重复提交直接复用已有快照，不额外生成分享内容；生成失败时保留前一份可用
  快照，已经可访问的看板版本不回退（版本只增不减）。
- 分享管理与看板组合快照引用同一份数据，并为看板组合链接生成**独立分享核验清单**
  （引用一致、图表组来源同步、看板版本同步、展示语义完整、配置版本可追溯）。
- 冲突决策：看板布局在「优先跟随看板刷新周期」与「优先等待图表数据就绪」之间冲突时，
  采用**优先跟随看板刷新周期**——到点即刷新，单张图表未就绪只标注该图表并保留其余
  图表，不清空整屏；刷新与分享读取同一份快照，不各自选取版本。

复核路径：自助看板 → 创建看板组合（勾选多张图表、指定列数与刷新秒）→ 确认生成组合 →
从看板行「分享链接」或组合快照列表打开分享视图；分享管理 → 对应链接行「核验清单」。
